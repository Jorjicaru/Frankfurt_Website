# Tourism and Culture Website — Frankfurt

A multi-page front-end website for presenting tourist attractions and accommodation options. Developed as an academic project using HTML, CSS, and vanilla JavaScript.

## Features

- Multiple connected HTML pages
- Responsive layouts using Flexbox and CSS Grid
- Navigation between destination and accommodation content
- Client-side validation for contact and reservation forms
- Shared styling and interactive navigation elements

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- JavaScript (vanilla)

## Run locally

1. Clone or download this repository.
2. Extract any resource archives into the locations expected by the HTML files.
3. Open the main `index.html` page in a modern browser.
4. Navigate through the links and test the front-end form validation.

The forms should be treated as front-end demonstrations unless a server-side booking/contact integration is explicitly configured. Client-side validation alone does not securely process or store reservations.
